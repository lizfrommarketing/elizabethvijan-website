# Real estate listing post workflow

The agent approves everything before it goes out. Never invent stats, testimonials, or sources. Keep the copy fair-housing compliant.

## Before the post
1. **Get the home and the hook.** Ask for the listing address and the hook. Ask for a one-word comment keyword (for example, MAGIC).
2. **Pull the facts from the MLS.** Get beds, full and half baths, square feet, lot size, community, key features, and the listing agent and brokerage. Use only what the MLS shows.
3. **Make the share link.** Create a public MLS share link for that single listing, then open it in an incognito window to confirm it works.
4. **Write the caption** in this order:
   - Comment "KEYWORD" and I'll send you the details, plus an emoji
   - A one-line tagline built from the hook
   - Beds, baths and square feet, each on its own line with an emoji
   - Three ✨ feature lines
   - A short closing line
   - For a quicker response, text or call [agent phone]
   - Not the one? Send me a DM to start your search.
   - Listing courtesy of [listing agent], [brokerage]
   - [Agent name] | [Agent brokerage]
   - Rules: no price in the caption, no street address, and always credit the listing agent.
5. **Write the on-screen text** as two copyable code blocks, with no address:
   - City, ST
   - 4 Bed | 4/1 Bath | 3016 Sqft
6. **Write the auto-reply messages**, for a comment auto-responder such as Muse or ManyChat:
   - Comment reply: "Just sent you a message! 🙂"
   - DM: thank them for their interest, include the share link, invite them to see the home in person, and give the agent's phone number.
7. Send all of this to the agent for approval.

## Post
8. The agent posts the reel herself.

## After the post
9. **Keyword automation (ManyChat).** Duplicate an existing comment-keyword automation. Point it at the new reel, set the keyword, put the share link in the DM, and set it Live. If there are no posts yet, check for new ones a few times a day.
10. **Price comment (optional).** If the agent wants one, comment the list price and HOA from the MLS, for example "List price: $X | HOA: $Y/mo". Remind her to pin it in the Instagram app.
11. **Website.** Send the address, beds, baths, square feet, share link and post URL to whoever runs the website, so the home is added to the featured homes page.

## Ongoing, twice a day
12. Check new Instagram and Facebook comments and DMs. Draft replies, catch anyone the automation missed, and flag serious buyers. The agent approves every reply and sends DMs herself.
13. Follow up. Move interested people to a call or text, set up showings, and start a home search for anyone who says "not the one."

## Notes
- If a login is expired (MLS, ManyChat, Instagram, Meta Business Suite), stop and ask the agent to sign in. Don't guess.
- Links come only from the MLS or Zillow.
